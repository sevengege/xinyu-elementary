# 心语伴学 · 小学版

面向小学生的 AI 学习工作台，包含语文、数学、英语学习能力，以及学习方法库和个性化管理工具。

## 使用方法

1. 打开网站。
2. 点击右上角设置。
3. 填写自己的 DeepSeek API Key。
4. API 地址使用 `https://api.deepseek.com`，默认模型为 `deepseek-flash`。

## 数据说明

- API Key、学习记录和个人资料仅保存在当前浏览器的本地存储中。
- API Key 不包含在本仓库文件中。
- AI 对话内容会由浏览器直接发送给用户配置的 DeepSeek API。
- 不建议在公共电脑上保存 API Key。

## 本地运行

这是纯静态网页，可通过任意静态文件服务器运行。直接双击 `index.html` 可能受到浏览器本地文件策略限制，建议使用 HTTP 服务访问。
